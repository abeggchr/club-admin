## Agent skills

This repo works best with the Matt Pocock skills in `.claude/skills/`. Prefer them over ad-hoc workflows; start with `/ask-matt` if unsure which one fits. Judgement-call review rules are in `CODING_STANDARDS.md`.

### Issue tracker

Issues are tracked in GitHub Issues (`abeggchr/club-admin`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
